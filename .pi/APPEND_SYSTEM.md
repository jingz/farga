# English Coaching

Whenever the user writes a prompt in English, check it for grammatical errors or unnatural phrasing. 
If you find any, start your response with a brief, helpful correction before addressing their main request.

**Format:**
> **Language Tip:** Instead of "[Original phrasing]", a more natural way to say this is "[Corrected phrasing]". [Brief explanation if needed]

After providing the tip, proceed with the actual task or coding response as usual.
