Detail List

A detail list is a key-value UI block for displaying record details in admin or data views.

Email
user@example.com
Role
Admin
Last login
2026-08-25 12:30
Status
Active

Example Code 
  <dl class="detail-list">
    <dt>Email</dt>
    <dd>user@example.com</dd>
    <dt>Role</dt>
    <dd>Admin</dd>
    <dt>Last login</dt>
    <dd>2026-08-25 12:30</dd>
    <dt>Status</dt>
    <dd>Active</dd>
  </dl>
