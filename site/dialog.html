Dialog / Modal Component

The native HTML <dialog> element provides built-in accessibility, backdrop overlay, and top-layer positioning.

Interactive Example

Click the button below to open the modal. Use the close button or press Esc to dismiss.

Confirm Action

Are you sure you want to proceed with this operation? This action cannot be undone.

Example Code 
<button type="button" onclick="document.getElementById('demo-dialog').showModal()">
  Open Dialog
</button>

<dialog id="demo-dialog" role="alertdialog">
  <header>
    <h3>Confirm Action</h3>
  </header>
  <p>Are you sure you want to proceed with this operation? This action cannot be undone.</p>
  <footer>
    <form method="dialog">
      <button class="btn-outline" value="cancel">Cancel</button>
      <button class="btn-danger" value="confirm">Confirm</button>
    </form>
  </footer>
</dialog>
