Empty State

Shown when a list, table, search or inbox has nothing to display. A blank surface tells the user nothing: name what would appear here and offer the action that creates it.

Basic

No saved words yet

Words you save while reading will show up here, newest first.

Browse today's words

Example Code 
<div class="empty-state">
  <h3>No saved words yet</h3>
  <p>Words you save while reading will show up here, newest first.</p>
  <a class="btn btn-small" href="#">Browse today's words</a>
</div>
