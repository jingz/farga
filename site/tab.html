Tabs

Tabs come in 2 variations

1. Basic Tabs

These tabs require JavaScript for toggling between different tab panels

  • Introduction
  • Get Started
  • Tutorials
  • Changelog

Accessibility Features:

Keyboard navigation with arrow keys, Home, and End keys Proper focus management Screen reader support through ARIA attributes Clear visual indicators for active and focused states

Example Code 
  <nav class="tab">
    <ul>
        <li><a>Introduction</a></li>
        <li class='active'><a>Get Started</a></li>
        <li><a>Tutorials</a></li>
        <li><a>Changelog</a></li>
    </ul>
    <section>
        <h3>Accessibility Features:</h3>
        <p>
        Keyboard navigation with arrow keys, Home, and End keys
        Proper focus management
        Screen reader support through ARIA attributes
        Clear visual indicators for active and focused states
        </p>
    </section>
  </nav>

2. Radio Tabs

This semantic approach does not require JavaScript to switch the active content according to the selected tab. Building a tab component with Pure CSS using Radio and Label Tags

Introduction Content

Introduction Features: Keyboard navigation with arrow keys, Home, and End keys Proper focus management Screen reader support through ARIA attributes Clear visual indicators for active and focused states

Get Started Content

Get started Features: Keyboard navigation with arrow keys, Home, and End keys Proper focus management Screen reader support through ARIA attributes Clear visual indicators for active and focused states

Tutorials Content

Tutorials Features: Keyboard navigation with arrow keys, Home, and End keys Proper focus management Screen reader support through ARIA attributes Clear visual indicators for active and focused states

Changelog Content

Changelog Features: Keyboard navigation with arrow keys, Home, and End keys Proper focus management Screen reader support through ARIA attributes Clear visual indicators for active and focused states

Example Code 
  <nav class="tab tab-radio">
      <input type="radio" name="tab" id="tab1" checked />
      <label for="tab1">Introduction</label>
      <section>
          <h3>Introduction Content</h3>

            Keyboard navigation with arrow keys, Home, and End keys
            Proper focus management
            Screen reader support through ARIA attributes
            Clear visual indicators for active and focused states
          </p>
