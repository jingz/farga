2. Radio Tabs

This variant switches content without JavaScript by pairing a radio group with its labels. The radios stay in the tab order, so Tab reaches the group and the arrow keys change the selected tab; the focus ring is drawn on the label. Building a tab component with Pure CSS using Radio and Label Tags
